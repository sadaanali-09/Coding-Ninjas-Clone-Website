# Coding Ninjas Clone

This project is a clone of the Coding Ninjas website, built using React and styled with Tailwind CSS. The aim is to replicate the functionality and design of the original site while providing a learning experience in modern web development practices.

## Features

- Responsive design using Tailwind CSS
- Functional components for modularity
- Routing setup for different pages
- Reusable components for common UI elements

## Project Structure

```
coding-ninjas-clone
├── public
│   └── index.html          # Main HTML file
├── src
│   ├── assets              # Directory for image assets
│   ├── components          # Reusable components
│   ├── data                # Static data for the site
│   ├── pages               # Different pages of the application
│   ├── styles              # Global styles
│   ├── App.tsx             # Main application component
│   ├── main.tsx            # Entry point for the React application
│   └── vite-env.d.ts       # TypeScript definitions for Vite
├── .gitignore              # Files to ignore in Git
├── package.json            # Project metadata and dependencies
├── postcss.config.js       # PostCSS configuration
├── tailwind.config.js      # Tailwind CSS configuration
├── tsconfig.json           # TypeScript configuration
├── tsconfig.node.json      # Node.js specific TypeScript configuration
└── vite.config.ts          # Vite configuration
```

## Getting Started

To get started with the project, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd coding-ninjas-clone
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm run dev
   ```

5. Open your browser and go to `http://localhost:3000` to see the application in action.
